# smb-glitch-levels
A compilation of screenshots of every glitch level in Super Mario Bros. There are 65,536 of them!

In reality, there are not many unique glitch levels in the game, but with 65,536 addresses to access, we can see where each leads in the game's memory.
This is a collection of screenshots having accessed EVERY address.

Enjoy!

# Some notes:

When the button input (bottom left) has a red outline, that means that the level crashes the console. A black outline is the norm. You can see this by the multitude of crash "black-screen" levels.

The emulator used was MesenRTA by threecreepio: https://github.com/threecreepio/mesenrta

The ROM used for glitch levels was by threecreepio: https://github.com/threecreepio/smb-glitchedworlds
